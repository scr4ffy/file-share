# Передача файлов напрямую между устройствами

Сайт из четырёх статических файлов. Файлы идут напрямую между браузерами (WebRTC), на сервере не хранятся, размера ограничения нет (проверено на 4,5 ГБ, ограничение только диск получателя).

Файлы проекта (все должны лежать в одной папке):

- `index.html` — сам сайт
- `sw.js` — воркер для потокового сохранения больших файлов
- `peerjs.min.js` — библиотека WebRTC (PeerJS 1.5.5)
- `qrcode.js` — генератор QR-кода

## Как выложить бесплатно

Нужен хостинг с HTTPS (без него WebRTC и потоковое сохранение не работают). Любой из вариантов:

1. **GitHub Pages.** Создайте репозиторий, загрузите 4 файла в корень, в Settings → Pages выберите ветку `main` и папку `/ (root)`. Адрес будет `https://ваш-логин.github.io/имя-репозитория/`.
2. **Cloudflare Pages.** Workers & Pages → Create → Pages → Upload assets, перетащите папку.
3. **Netlify Drop.** Откройте app.netlify.com/drop и перетащите папку.

## Как пользоваться

1. Откройте сайт: вы увидите свой код и ссылку (код запоминается в браузере, ссылка постоянная).
2. Отправьте ссылку другу любым способом (или покажите QR-код).
3. Друг открывает ссылку, устройства соединяются, и любой из вас может перетащить файлы в окно.
4. Получатель нажимает «Принять» и выбирает, куда сохранить.

Обе вкладки должны быть открыты, пока идёт передача.

## Ограничения

- **Оба участника должны быть онлайн одновременно.** Файл не «лежит» на сервере.
- **Соединение может не установиться** у части пар устройств (мобильный интернет, строгие роутеры, корпоративные сети). Тогда нужен TURN-сервер, который пересылает трафик. Впишите его в массив `ICE_SERVERS` в начале скрипта в `index.html`:

  ```js
  { urls: 'turn:turn.example.com:3478', username: 'user', credential: 'pass' }
  ```

  Через TURN идёт весь трафик, поэтому у бесплатных TURN обычно есть лимит по объёму. Свой TURN можно поднять на VPS (coturn).
- **Сохранение больших файлов.** В Chrome, Edge и Opera на компьютере файл пишется прямо на диск. В остальных браузерах используется потоковая загрузка через Service Worker. Если и она недоступна (например, приватный режим Firefox), файл собирается в памяти, и для файлов больше 1-2 ГБ нужен Chrome или Edge.
- **Сервер сигналов.** Сайт использует бесплатный публичный сервер PeerJS (0.peerjs.com), который только помогает найти друг друга и не видит содержимого файлов. Гарантий доступности у него нет. При желании можно запустить свой (`npm i -g peer && peerjs --port 9000`) и открывать сайт с параметрами `?ph=адрес&pp=9000&ps=1&pa=/`.
